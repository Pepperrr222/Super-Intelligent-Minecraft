# 实验约定

第一阶段采用基础版报告的先导规模：6 类任务，每类 5 个独立场景，B0/B1 各 30 次，共 60 次。配置为计划清单，当前不包含自动重置或批量游戏执行器，也没有实验结果。

已有受控执行验收摘要位于 results/，用于证明特定原版动作与任务能执行；它不是上述60次学习对照实验，没有学习提升百分比。

任务类别见 tasks.json。先确保底层动作通过真实验收，再固定场景、初始背包、位置、容器、模型、提示词主体和动作预算。B0/B1 的唯一方法差异为跨任务经验检索。

经验采集、技能复验和最终评测使用不同场景。正式测试从相同冻结数据库副本开始；恢复世界后再执行下一次。任何取消、超时、失败都保留，人工帮助单独记录。Mock demo 不能混入游戏实验。

固定环境评测冻结记忆；当前 B1 默认结束写库，因此批量评测工具必须在每轮恢复数据库快照。规则变化实验另开独立记忆副本并使用同一序列与预算。

日志按模式/环境/场景/重复编号分目录。运行 `sim-evaluate` 汇总同一组任务日志。统计包含成功数、分母、结束状态、耗时、规划步数、实际模型调用、token 和动作数，规则/脚本不计实际模型调用。约束违反、技能复用和配对分析需要正式夹具补充。

开题 PPT 的完整计划为 12任务 × 3环境 × 4版本 × 3初始条件 = 432回合。待 B2/B3 和规则适配实现后启用，不能将尚未实现的方法放进实验表作为已完成版本。

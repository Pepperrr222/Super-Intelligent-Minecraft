## 启动

先正常停止旧伙伴，再双击根目录 `启动AI伙伴V2.cmd`。复用现有服务器、账号、owner 和模型配置；启动后应显示 `决策模式=v2`。`启动AI伙伴.cmd` 当前也默认使用 V2，V2 模型失败不会自动回退到技能。不要同时运行同一个 Bot 的两个入口。

也可在 PowerShell 使用：

```powershell
$env:SIM_AGENT_MODE = 'v2'
pnpm companion
```

唯一决策模型使用 `agent.model`（兼容旧 `agent.director`）或现有 `LLM_PLANNER_MODEL` 客户端。V2 不使用 `LLM_FAST_MODEL` 和单独的 `agent.executor`。没有模型时不回退到关键词动作；本地停止控制仍可用。

## 已实现

- 原话、补充、自然语言要求、剩余事项和当前批次分开保存。批次结束后主控继续判断，不直接关闭总目标。
- V2 控制器和调度器使用空技能注册表，只接受基本动作；旧技能代码保留在 legacy 模式，尚未物理删除。
- 同一个决策模型生成查询/动作/可选阶段并根据实际结果继续；finish 对照原话、修订和实际证据。程序检查要求覆盖、证据引用和待对账状态，不枚举全部任务的成功函数。
- 普通目标自主选择必要中间步骤、工具、配方、对象与参数；普通回复直接发送，不另经模型复核。
- 修改要求会使旧提案失效。停止与暂停拦住未开始步骤，在途原生操作未结束前仍持有租约。问进度不覆盖目标。
- 失败或重启存在未确认操作时，先观察，主控引用新证据对账后才允许新写操作，不自动重放。
- 等待加工采用有界定时唤醒，同时监听方块、拾取、血量和背包更新；闲置、暂停或等待玩家时不持续空转。

默认每目标最多 60 次模型调用、128 个写动作、15 分钟活动时间、24 小时绝对恢复期限；每次自主模型决策占额度，每批最多 4 个动作。耗尽后暂停并保留状态；明确“继续”可重开耗尽的有限轮次，暂停后明确 amend 也重开轮次，普通聊天和重启不会自动补额度。当前调参入口是 `CompanionRuntimeOptions.agent`。

## 持久化与边界

伙伴入口按服务器、端口、账号和认证方式生成存储标识，写入 Git 忽略的 `runtime/agent-*.jsonl`。直接构造 AgentLoop 默认使用内存，需传 FileAgentStore 才持久化。

游戏写操作入队前记录意图；日志使用完整性链、fsync 和单写入锁。每 64 次提交生成快照并归档旧日志段；启动读取快照及当前日志，忽略未写完整的尾行。完整记录损坏或存储写入失败时停止新增世界操作。

活动目标重启后先对账，在原授权与期限内可自主继续；已暂停/取消目标不自动恢复。崩溃锁仅在确认旧进程不存在后回收。若锁回收本身中断留下 `.reclaim` 标记，需要检查旧伙伴已退出后再处理，不能运行中直接删锁。

目前实现的是持续任务记忆；当前目标可按证据 id 读取历史。跨历史目标的自动经验检索、长期偏好学习和自然语言记忆编辑尚未实现。归档不自动删除，长期运行需关注磁盘占用。

语义复核与验收仍可能误判；它们不是数学证明。上下文超限会暂停，不偷偷裁掉完整目标。客户端不一定能证明掉落来源或玩家收到物品。现有按名称 equip 对同名不同属性物品的精确选择仍有限制。

## 接口与验证

模型操作显式要求 `equip.destination`、`place.face`、`navigate.range`、`follow.distance`、`look_at_entity.part`、`use_item.offHand`、`use_item_ticks.offHand`、`furnace_take.minCount`；原生动作 API 的默认值暂留兼容，模型入口不再继承这些默认。真正可选参数、分页与查询上限仍保留。

新增只读 `register_position` 查询，将 32 格内已加载整数坐标注册为短期 position 引用，可导航/看向但不能作为挖掘/容器目标，不证明可达；远距离探索需分段观察。snapshot 增加 heldItem，掉落实体与 observe_targets 增加解码的物品名/数量或 unknown。当前为 45 动作、12 查询、44 模型操作。

`pnpm build`、`pnpm schema`、`pnpm test` 通过。新增测试覆盖跨批次、内部纠错、虚构证据、停止、写前存储失败、恢复不重放、统一预算、回复复核、日志完整性/检查点、等待时聊天、澄清原话、运行中修订、验收漏项、位置引用、默认值、装备/掉落观察和空技能入口。首次沙箱 HTTP/原子重命名因 EACCES/EPERM 失败，允许本地操作后完整 275 项通过。未连接游戏、未调用真实模型。

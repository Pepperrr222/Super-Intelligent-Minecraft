# 规划与执行面板

面板展示上层模型接口实际提供的思考文本、最终决策输出，以及当前目标与约束、世界观察、执行反馈、重规划、最终验证和用量。思考区读取 reasoning_content 原文，不调用另一个模型总结，也不补写未提供的内容。思考和最终决策互相隔离；程序不会把思考文本当作动作或成功依据。

本机配置中 model.thinking=true、model.stream=true 可开启实时思考。DeepSeek 与 SiliconFlow 的参数由适配层分别转换；旧配置默认不启用流式，仍然可用。升级后重启 Agent 生效，原有时间和输出预算不会自动增大。

## 使用

在仓库根目录运行，Windows 无需激活环境：

```powershell
.\.venv\Scripts\python.exe scripts/dev.py run --config config.json --dashboard
```

浏览器打开终端打印的 http://127.0.0.1:8765 。已在运行的旧 Agent 需要重启，才能写出逐步决策记录；无需重启 Minecraft 服务器。

内置面板随 Agent 关闭。如果希望保持面板、查看历史，另开终端独立启动：

```powershell
.\.venv\Scripts\python.exe scripts/dashboard.py --config config.json
```

默认只允许本机访问。如需让同一局域网的队友用浏览器查看，可显式使用 `--host 0.0.0.0`，让队友访问本机局域网 IP 的 8765 端口。面板只有只读接口，没有登录和指令执行接口；不要映射到公网。端口冲突时用 `--port 8766`，内置模式用 `--dashboard-port 8766`。

## 如何阅读

顶部“上层模型思考输出”按规划调用展示原文。下拉菜单可以回看同一任务中的历史调用，最终决策在独立折叠区。调用完整结束只表示输出接收完成，仍须通过后续 JSON、目标、约束和动作校验；不等于任务完成。

正在接收、已取消、已超时、达到上限、连接中断和调用失败分别标记。取消或中断后已经收到的部分仍可查看；没有收到思考时，会区分关闭与接口未提供。原文中即使出现 JSON 或动作名称，也不会交给执行器。

- “规划请求”：正在等待规划器根据当前观察提出下一步。
- “模型提案”：结构已经解析，目标含义和动作仍可能被后续校验拒绝。简短说明由模型公开提供，可能出错。
- “目标已锁定”：程序接受了可检查的目标谓词；尚不代表任务完成。
- “执行步骤 / 反馈”：实际查询或动作及返回证据。参数校验失败也会显示。
- “独立完成验证”：程序重新观察并核对目标；未通过会反馈下一轮，不能记作完成。
- “任务结束”：完成、失败、取消、等待澄清或预算耗尽。

这是一套单步反馈规划器，不会事先编造完整远期计划。时间线展示实际发生的步骤。模型省略公开说明时只显示它提出的操作，不补写解释。

可以筛选规划、动作和异常；点击任务切换历史，取消“跟随最新任务”后保留当前选择。“暂停刷新”仅暂停页面读取，游戏中的 Agent 仍继续运行。

## 日志与边界

新时间线写入配置的 runtime_dir 下 trace.jsonl。原有 tasks.jsonl、requests.jsonl 和 usage.jsonl 继续保留。每次模型调用以 call_id 在 model-calls/ 中保存增量 .jsonl 和结束后的完整 .json，index.jsonl 提供按任务检索的元数据。页面展示的是接口原文；不保存完整 HTTP 响应、请求提示词或密钥。旧版日志只展示已有摘要，不伪造缺失的思考。

时间线和调用索引各读取末尾2MB，最多展示600条时间线事件和20个任务。选定调用单独读取，页面读取窗口上限16MB，超出时明确提示；不把较早的思考片段混进时间线窗口后丢失。正在写入时忽略不完整行；进程异常退出留下的增量文件仍保留。更早的证据保存在本机文件中，页面会提示历史窗口受限。

用量来自 API 返回记录，错误响应可能缺少用量，不能当作完整账户账单。页面读取成功仅表示面板进程可访问，不证明 Agent 仍在线；任务中断而未留下结束记录时，要结合终端判断。

离线演示仍标记为 scripted-demo；规则或脚本没有模型思考，不会生成模拟思考内容。面板读取不额外调用模型；启用模型思考本身可能增加调用时间和用量。面板不改变玩家权限、动作能力、步数预算或完成验证逻辑。

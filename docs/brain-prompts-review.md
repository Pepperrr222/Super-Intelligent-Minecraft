# 大脑提示词审阅包

由 pnpm prompts:export 从实际运行注册表生成，不手工维护提示词副本。

版本：sim-v2-9。审批标识：

`9107c2b4610d83ee18be53ac16055c4102fa41eaf76f775b6ffd663881cd762b`

sim-v2-9 合并为唯一 decision 角色：同一个模型理解消息、选择查询/动作/可选阶段、根据结果纠错并判断完成。不再调用主控、执行或独立验收模型。统一方块/实体 ref，区分方块名、实体名和掉落物内容过滤。

此文件包含每个角色完整的 system 消息（角色前缀、正文、输出 Schema），以及动态 user 消息模板。实际玩家原话、实时观测、目标和错误无法提前固定；这些值按下列模板填入，不另加隐藏提示词。finish 使用同一目标上下文；程序核对要求覆盖和证据引用，但不宣称能证明所有自然语言语义。

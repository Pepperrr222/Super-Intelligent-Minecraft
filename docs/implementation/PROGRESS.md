## 已实现

- Coordinator 接收原始命令和高层事实，描述业务阶段与自然语言完成标准。
- Worker 独立选择底层动作，编译根交付与阶段验收。
- 独立 LLM Reviewer 已移除；程序保留参数、权限、预算、基线、取消、状态验证与回复回执。
- 面板展示角色、模型输出、阶段、编译事件与执行反馈。
- 执行期间接收获准玩家的新指令，Coordinator 可回答、排队、替换、修订、暂停/恢复和终止子任务；停止、断线和关闭使旧调度失效。
- 简单问答可一次高层调用完成，简单行动可一次delegate派发；Worker 验收可附在首次动作中。相同验收重复准备幂等确认，成功后清理旧修复上下文。
- 新架构须显式启用 hierarchical，只支持 B0。默认模式仍为 legacy。

职责以 [架构修订](COORDINATOR_AUTONOMY.md) 为准，启动见 [运行说明](RUNNING.md)。

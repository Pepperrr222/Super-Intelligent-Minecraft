# 能力与验收边界

本文件区分代码能力、离线验证和真实游戏验收。没有实际运行记录时不声明真实世界通过。

## 本次仓库建设

已将原有 Python 决策层重组为分层包，保留 Mineflayer 执行器，增加 SQLite 轨迹、B1 检索、技能复验存储接口、离线演示、日志评测和跨平台入口。

Python 测试覆盖目标锁定、库存基线、世界切换、模型虚报完成、取消和迟到响应、忙状态、传输超时、经验作用域和技能晋升。Node 测试覆盖动作生命周期、互斥、取消、部分效果、槽位读取、拾取判据、参数校验及协议并发。

离线 demo 验证固定脚本与 Mock 后端之间取料、合成、存放、最终检查和持久化能连通。它不验证真实移动、服务器同步、模型指令理解或学习效果。

CI 配置覆盖 Windows/Linux 和 Python 3.12/3.13；只有远端 CI 实际运行成功后才能称为跨平台验收通过。

## 已知限制

- 仅原版命名空间和普通动作；没有整合包兼容验收。
- 配方依赖 Mineflayer 版本注册表，尚无自定义服务器规则发现通道。
- 不支持任意 GUI、复杂机器、代码生成、完整从零生存。
- 当前执行器仅支持本机实验服 offline 认证。
- 一个任务只锁定一个完成谓词，复合目标和全程资源约束尚未程序化。
- 忙碌时拒绝新任务，尚未支持执行中纠正目标；可停止后重发。
- 候选技能需要显式复验记录，尚无自动抽取、参数绑定和技能执行器。
- SQLite 依赖指纹接口不等于已经具备自动规则变化适应能力。

真实结果、版本、场景配置和模型信息应随实际验收补充，失败记录也必须保留。
